# Product Images Setup Guide

## Overview
This app requires **110 product images** to be placed in the `assets/images` directory. Follow the instructions below to download and organize all images.

## Directory Structure
```
assets/images/
├── oils/         (25 images)
├── flours/       (22 images)
├── beauty/       (23 images)
├── health/       (20 images)
└── snacks/       (20 images)
```

## Quick Setup - Automated Download

### Option 1: Run PowerShell Script (Recommended)
```powershell
cd C:\ConsitencyProject\flutter_application_1
powershell -ExecutionPolicy Bypass -File .\download_images.ps1
```

This will automatically download all 110 product images to the correct folders.

### Option 2: Manual Download
If the script fails due to network issues, download images manually using the list below.

## After Downloading

1. **Verify all images are in place**:
   ```powershell
   Get-ChildItem -Path assets\images -Recurse -File | Measure-Object
   # Should show 110 files
   ```

2. **Run Flutter pub get**:
   ```bash
   flutter pub get
   ```

3. **Hot reload or restart the app**:
   ```bash
   flutter run
   # OR press 'R' in the running app terminal
   ```

## Troubleshooting

- **Images not showing**: Make sure to run `flutter pub get` after adding images
- **File not found errors**: Check that image filenames match exactly (case-sensitive)
- **Download failures**: Try using a browser download manager or wget/curl commands
